# S2 村口木石小屋 / 山居

## 用户输入（喂给交互 agent）

> 老家村口有块坡地，想盖一间小房子，周末回去住。想要石头基座、木头墙、深色瓦屋顶，看起来像村里原来的房子，但里面要干净、亮一点。一层要有厨房、客厅和一个小卧室，二层做卧室和储物，楼梯要好走。房子不要太大，两个人住，偶尔孩子回来。门口想有个能坐的小平台。预算有限，能住就行，但不要太简陋。

## 评阅关注点（不要喂给 agent）

### 必须主动澄清 / 决定

- 坡地坡度 / 朝向 / 道路在哪一侧？入口从高处还是低处进？
- “两层”是完整二层，还是带阁楼 / 夹层？楼梯位置与净高。
- 一层卧室是给老人 / 客人？是否需要卫生间？卫生间在一层还是二层？
- 厨房是封闭还是开放式？是否需要柴火 / 储粮 / 农具空间？
- 冬季保暖 / 夏季通风的优先级；是否需要火炉 / 烟囱。
- 预算有限时，哪些是 must：结构安全、楼梯、防水、厨房、卫生间？

### 预期方案深度

- 坡地嵌入 / 基座 / 挡土墙；入口与道路关系；小平台。
- 两层：一层厨房 / 客厅 / 卧室 / 卫生间；二层卧室 / 储物；楼梯位置、踏步、平台、净空。
- 结构：石基 + 木框架 / 木墙 + 双坡瓦屋面；跨度与楼梯洞口。
- 室内：厨房台面 / 储物、餐桌、沙发 / 座椅、床、衣柜、书架、灯具、地面材质。
- 外观：石基、木墙、深瓦、窗框 / 窗台 / 门廊；真实人体尺度。
- 细部：楼梯栏杆、檐口、屋脊、烟囱、排水、入口门槛。

### 故意设置的坑

- “两层 + 楼梯”与“预算有限”冲突；要说明楼梯 / 楼板 / 二层带来的成本。
- 坡地入口如果处理不好，会出现“半地下”或高差过大；需要明确标高。
- “像村里原来的房子”不是复制符号；要控制比例与材料，不做旅游民宿。
- 室内不能只画家具名；需要位置、尺寸、动线。
