# S4 小型院落 / 民宿

## 用户输入（喂给交互 agent）

> 想在村里做一个小院子，两栋小房子，一栋自己住，一栋做民宿客房。想要围起来，进门有个小院，能喝茶、晒东西。房子不要高，最多两层，最好有木和石头的质感，屋顶深色。院墙不要太高，能看到一点外面。客房要有独立卫生间，自己住的那栋要有厨房和客厅。预算中等，先做两栋和院子，景观可以简单。

## 评阅关注点（不要喂给 agent）

### 必须主动澄清 / 决定

- 场地尺寸 / 道路 / 周边民房 / 朝向；主入口从哪边进？
- 两栋的功能分配：自住 / 客房；客房几间？是否需要公共厨房 / 早餐区？
- 院墙高度与“能看到外面”的矛盾：多高、用什么材料、是否透空。
- 客房独立卫生间：上下水 / 排污 / 通风怎么解决？
- 两层是否必要？楼梯与二层的使用。
- 预算中等时，景观做到什么程度；停车 / 后勤。

### 预期方案深度

- 总平面：院墙、门楼 / 院门、两栋位置、院内铺装、茶座、晾晒 / 绿化。
- 两栋平面：自住（厨房 / 客厅 / 卧室 / 卫生间）、客房（卧室 / 卫生间 / 入口）。
- 结构：石基 / 木结构 / 双坡屋面；院墙与门楼。
- 外观：木石、深瓦、院墙高度、门楼、窗 / 门 / 檐口。
- 室内：家具、床、衣柜、书桌、厨房台面、卫生间洁具（用方块近似）。
- 场地：铺装、台阶、绿化、排水、室外家具、灯。

### 故意设置的坑

- “院墙围起来”与“能看到外面”冲突；需要高度 / 透空 / 材料取舍。
- 两栋 + 院子 + 室内 + 卫生间，预算中等容易超；要明确优先级。
- 客房卫生间涉及排水 / 通风，当前方块可以表达但需要设计说明。
- 不要把两栋做成完全相同的复制体；主次、朝向、入口要不同。
