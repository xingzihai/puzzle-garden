# S1 溪畔茶亭 / 咖啡亭

## 用户输入（喂给交互 agent）

> 村口溪边有一块空地，想做个小小的茶亭，路过的人能坐下来喝点东西，看看水。最好有点木头的温暖感，屋檐大一点，下雨也能坐。室内能坐十个人左右，要有个小柜台，能烧水、放杯子。预算不要太高，别做成景区售票亭那种。你帮我看着设计吧，我不太懂尺寸。

## 评阅关注点（不要喂给 agent）

### 必须主动澄清 / 决定

- 溪在场地哪一侧？主要视线朝水还是朝村道？
- 入口从村道还是溪边进入？是否需要一个小平台 / 台阶？
- “室内坐十人”是十个座位还是十个人同时站立 / 喝茶？是否需要卫生间？
- 柜台只是备茶，还是要简单清洗 / 储物 / 小厨房？
- 屋檐“大一点”是 0.9 m、1.2 m 还是 1.8 m？需要和墙高、窗高一起决定。
- 预算“不要太高”对应多少方块 / 多少费用？至少给一个建议范围。

### 预期方案深度

- 场地与入口序列：村道 → 门槛 → 室内 → 檐下平台 → 溪边。
- 主体约 8×6–12×8 m，一层；檐下平台 6–12 m²；室内 10 座。
- 平面：主茶室、柜台 / 储物、入口玄关、檐下平台；可行的话加一个小卫生间或预留。
- 结构：石台基 + 木柱 / 木墙 + 双坡或四坡深瓦屋面；檐口 1.0–1.5 m。
- 室内：长桌 / 坐凳 / 靠窗长凳 / 柜台 / 书架 / 灯具 / 地面材质；不能只给家具名。
- 材质：石基、暖木、浅石框、深瓦；3–4 档明度。
- 细部：窗框、窗台、门槛、檐口收边、屋脊、排水、灯具。

### 故意设置的坑

- “屋檐大一点”可能导致超大屋檐压墙；方案要控制外挑与墙高比例。
- “室内坐十人”与“预算不要太高”可能冲突；应给取舍。
- “看看水”需要朝向与开口设计，不能只放一扇小窗。
- 不要做成旅游售票亭：避免大招牌、售票窗口、过度装饰。
