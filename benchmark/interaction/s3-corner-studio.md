# S3 街角工作室 / 小书店

## 用户输入（喂给交互 agent）

> 想在街角开一家小书店，兼做工作室。房子两层，一层卖书和咖啡，二层做办公和存放。街角两面要通透，能看到街上的树和行人，但不要做成玻璃盒子。想要现代一点，浅色墙、深色金属框、平屋顶。入口要明显，最好有个小雨棚。面积不用太大，但要有厕所和一个小仓库。预算中等，先做外立面和一层的书店，二层可以简单一点。

## 评阅关注点（不要喂给 agent）

### 必须主动澄清 / 决定

- 街角哪两条街？主要人流方向？入口开在转角还是次街？
- 一层书店 + 咖啡：是否需要厨房 / 吧台 / 座位 / 无障碍厕所？
- 二层“简单一点”是毛坯、办公、仓库还是可出租？楼梯是否必须到二层？
- 平屋顶是否需要上人 / 设备 / 女儿墙 / 排水？
- 街角两面“通透”与“不要玻璃盒子”如何平衡：窗带、竖梃、实墙比例。
- 预算中等时，外立面 / 一层 / 二层分别做到什么程度。

### 预期方案深度

- 场地与街角关系：主入口、橱窗、行人视线、后勤入口。
- 两层平面：一层书店 / 咖啡吧台 / 座位 / 厕所 / 仓库；二层办公 / 储物 / 楼梯。
- 结构：柱网 / 墙承重、平屋顶、女儿墙 / 排水；二层楼板与楼梯洞口。
- 外观：浅色墙、深色金属框、水平带窗 / 竖向分格、转角处理、入口雨棚。
- 室内：书架 / 展台 / 收银 / 吧台 / 座位 / 灯具 / 地面；二层工作桌 / 储物。
- 细部：窗框、窗台、女儿墙压顶、雨水口、入口门槛、雨棚。

### 故意设置的坑

- “街角两面通透”与“不要玻璃盒子”需要比例与分格设计，不能全玻璃。
- “先做一层，二层简单”可能导致二层空壳 / 无楼梯；要明确交付范围。
- 平屋顶容易无收口；需要女儿墙、压顶、排水。
- 书店 / 咖啡混合功能容易动线混乱；需要柜台、座位、后勤分区。
