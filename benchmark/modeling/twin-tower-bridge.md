# 双塔连桥：草模 agent 验证题

## 一、目标

设计一组“双塔连桥”粗草模：两座高度不同的塔楼，各自向上收分；两塔之间架一条连接廊桥；整体坐落在一个低矮的公共基座上。

两座塔必须使用绕轴旋转的曲面壳体，且两塔的收分规律要明显不同——一座下部挺拔、上部快速收束；另一座下部舒展、上部保持饱满。轮廓由你自行设计函数或贝塞尔曲线，不要两座都用普通圆锥。

## 二、表达粒度

只表达塔身体量、曲面轮廓、廊桥与基座。不做墙体厚度、门窗、栏杆、电梯、设备或任何装饰细节。

廊桥两端应实际接到两座塔的塔身，不悬空；塔身与基座相接，不互相穿模。曲面不能出现非有限数、自交或明显破面。

## 三、规模与自由度

整体水平占地不超过 90×90 设计单位，最高塔总高不超过 70，矮塔不超过 40。每座塔有稳定编号、可读名称；两塔、廊桥、基座使用不同素色便于辨认。

不指定具体公式、分段数、半径与位置细节；在上述目标内自行设计。允许在塔顶设置一个小型观景环或收口构件。

## 四、交付

提交成功执行的建模代码和网格，并附提交说明：两座塔的曲线思路与区别、看图后做过的调整、仍然存在的问题。交付前至少实际查看一次当前模型图片。
