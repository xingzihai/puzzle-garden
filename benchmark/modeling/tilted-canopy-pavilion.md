# 倾斜曲面亭：草模 agent 验证题

## 一、目标

设计一座观景亭粗草模：一个低矮的长条形基座；顶上覆盖一片倾斜的曲面屋顶——屋顶整体绕水平轴倾斜，一侧压低、一侧抬高，形成定向出挑；另设一个细小的塔状竖向构件，与屋顶在空间上咬合。

曲面屋顶的轮廓必须由你自行设计的函数生成（例如在收分基础上叠加波动或幂律变化），不要使用普通圆锥或柱面。竖向构件同样用曲面壳体。

## 二、表达粒度

只表达基座、倾斜曲面屋顶和竖向构件。不做墙体、门窗、栏杆、柱子阵列或任何装饰细节。

倾斜屋顶的最低点不能没入基座；竖向构件与屋顶相接处不得有明显穿模。曲面不能出现非有限数或自交。

## 三、规模与自由度

整体水平占地不超过 80×50 设计单位，总高不超过 35。各部件的倾斜角、曲率、波动幅度与相对位置自行决定，但需在提交说明里写清。

## 四、交付

提交成功执行的建模代码和网格，并附提交说明：屋顶函数与倾角的思路、看图后做过的调整、仍然存在的问题。交付前至少实际查看一次当前模型图片。
