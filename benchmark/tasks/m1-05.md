# M1-05 城楼 · 街口鼓楼

> task_id: `m1-05` ｜ family: `m1-drum` ｜ split: **m1** ｜ 难度：难（备用第 2 道）
> 下部厚墩台 + 上部楼阁两部件，穿行券洞 + 登台楼梯；只做外观与可进入，不做内饰（决策 #36）。

## 一、must

1. **墩台**：下部一座方正的实墙墩台（外墙围合、内部留空），高 6–9 格，墙体厚重（厚 ≥ 2）。
2. **穿行券洞**：墩台南北两面正中各开一个**拱形券洞**（券顶收口），净宽 3–5、净高 4–6，南北贯通，人能从南面草地直穿到北面草地。
3. **登台**：墩台内部（券洞以外的空间）一部楼梯从地面通到墩台顶面；墩台侧面开一扇门进楼梯间，门洞贯通、不填实；踏步连续、无断梯、无悬空。
4. **台顶平台与栏杆**：墩台顶为可站人的平台，外沿一圈栏杆（或女儿墙），楼梯出口处留口。
5. **上部楼阁**：台顶正中一座单层楼阁，外墙围合、四面各开 1 扇门或窗，至少一扇门从台顶平台走得进；楼阁四周留出 ≥ 2 格宽的回廊平台。
6. **楼阁屋顶**：四坡或攒尖，出檐 ≥ 1 格，可加顶饰（顶饰须落在屋顶尖端上）。
7. **材质分区**：墩台石砖系（深色或带苔），楼阁墙木材，屋面深色。

## 二、forbidden

- 禁圆形墩台或圆形楼阁。
- 禁在楼阁上再叠第二层楼阁。
- 禁城墙延伸、街道、牌坊群、树群等扩展场景。
- 禁斜角唯一相接或悬空的楼梯；禁无收口券洞。

## 三、尺寸/规模范围

| 项               | 范围          |
| ---------------- | ------------- |
| 墩台外轮廓       | 15–21 × 13–17 |
| 墩台高           | 6–9 格        |
| 楼阁墙体外轮廓   | 7–11 × 7–9    |
| 楼阁墙高         | 4–6 格        |
| 最高点（含顶饰） | 18–26 格      |
| 实体方块预算     | ≤ 22,000      |

## 四、风格与可观察条款

- 意图：**下重上轻**：厚墩台托起轻巧楼阁，券洞是街口的通道。
- 可观察：券洞贯通与收口、登台楼梯连通、台顶栏杆、楼阁居中与回廊宽度、材质上下分区。
- 只可观察、不可机械证明：庄重感、上下体量比例。

## 五、交付与执行

同统一循环（不喂给模型）。

评判要点（给人看，模型看不到）：

- 机械：南草地 ↔ 券洞 ↔ 北草地贯通；草地 → 楼梯间门 → 楼梯 → 台顶 → 楼阁门全程连通（硬要求）。
- 机械：券洞与楼梯间互不挖穿（楼梯不得侵入券洞净空）；无悬空。
- 目测：券洞为拱形且收口；台顶栏杆除出口外连续；楼阁四周回廊 ≥ 2。
- 目测：石墩台 / 木楼阁 / 深色屋面三段材质可读。
- 若楼阁直接压在台顶外缘、无回廊，记为 must 5 未满足。
