# M1-04 客舍 · 带屋顶露台的驿站

> task_id: `m1-04` ｜ family: `m1-inn` ｜ split: **m1** ｜ 难度：中偏难（备用第 1 道）
> 单栋两层 + 可上人平屋面，两段楼梯；只做外观与可进入，不做内饰（决策 #36）。

## 一、must

1. **两层驿站**：外墙围合，内部留空，**两层**，二层有一整块楼板。
2. **入口**：南面正中一扇门，净宽 ≥ 2、净高 ≥ 3，门洞贯通、不填实；门洞底高于草地时配上台踏步，从草地能走进一层。
3. **平屋面露台**：屋顶为平屋面，四周一圈女儿墙（高 1–2 格），露台面可以站人。
4. **楼层可达**：室内楼梯从一层地面通到二层楼板面，再从二层通到屋顶露台面；两段都踏步连续、无断梯、无悬空，每个落脚处有净空。
5. **露台小屋**：露台一角一间小梯间（楼梯出口罩在里面），有自己的小坡屋顶或平顶，开口朝向露台，从梯间能走到露台上。
6. **开窗**：每层每面至少 1 扇窗。
7. **材质倾向**：墙以砖或石砖为主，窗台/女儿墙压顶用另一种浅色石料。

## 二、forbidden

- 禁第三个整层；梯间小屋不得做满整个屋面。
- 禁院墙、马厩、道路网、树群等扩展场景。
- 禁室外楼梯；禁斜角唯一相接或悬空的楼梯。
- 禁女儿墙留出可坠落的大缺口（梯间开口处除外）。

## 三、尺寸/规模范围

| 项                   | 范围          |
| -------------------- | ------------- |
| 墙体外轮廓           | 13–17 × 11–13 |
| 层高                 | 4–6 格        |
| 主体墙高（到露台面） | 9–13 格       |
| 梯间小屋外轮廓       | 4–6 × 4–6     |
| 最高点（梯间屋顶）   | 14–19 格      |
| 实体方块预算         | ≤ 16,000      |

## 四、风格与可观察条款

- 意图：**方正敦实的体块，顶上一个小凸起**；露台是看点。
- 可观察：入口、两段楼梯连通、露台女儿墙是否围合、梯间小屋位置与开口、开窗分布、材质压顶。
- 只可观察、不可机械证明：体块比例、压顶线条观感。

## 五、交付与执行

同统一循环（不喂给模型）。

评判要点（给人看，模型看不到）：

- 机械：草地 → 门 → 一层 → 二层 → 露台面全程连通（硬要求）；无悬空。
- 机械：女儿墙除梯间开口外连续；梯间小屋尺寸在范围内且不占满屋面。
- 目测：每层每面 ≥ 1 窗；砖墙 + 浅色压顶可读。
- 若楼梯第二段直接从屋面开洞冒出、无梯间罩住，记为偏题（must 5 未满足）。
