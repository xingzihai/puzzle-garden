# M1-08 地下 · 地下铁电影院商业街组合体

> task_id: `m1-08` ｜ family: `m1-plaza` ｜ split: **m1** ｜ 难度：最难（三层立体 + 多部件 + 多类内饰 + 全程连通）
> 由 owner 原版提示词（`docs/prompts/underground-plaza-original.md`）改写，2026-10-09。按 owner 指示"修改相对位置，把整个建筑最底下作为海平面"：组合体整体上移，**最底层（原地下三层·电影院）楼面落在 y = 1**，向上依次叠站台层（原地下二层）、商业街与站厅层（原地下一层），原"地表"的公园 / 人行道 / 马路成为**顶层街面**。相对位置与连通关系全部保留，"地下第 N 层"只是上移后的相对说法，"向下"仍指 y 减小方向。
> 与 M1-07 不同：本题**要求做内饰**（三间店铺、站厅、影院），且全部结构在 y ≥ 1（y ≤ 0 不写方块、不渲染、悬空测量失真）。
> 第三、四节的尺寸数字为改写者拟定（原版没有数字），只是验收范围，可再调。

## 一、must

1. **总体与坐标**：组合体是竖着叠的三层建筑：**底层 = 电影院**、**中层 = 地铁站台**、**上层 = 商业街 + 地铁站厅**，**顶层街面**（原"地表"）在商业街层之上。海平面 y = 0 不写任何方块，最底层楼面从 y = 1 起；各层上下对齐，不悬空、不互相穿模。
2. **顶层街面**：除两个出入口外，组合体正上方那片区域做**公园**（草皮、树、花丛、小径，按规律或对称布置）；公园向外依次是**人行道**（配路灯，等距）和**马路车道**（铺装可辨、有车道分隔）。三者同处顶层标高，由下方结构或立柱承托，不整片悬空。
3. **出入口 ×2**：玻璃框架、单面开口的**三角柱体**（三角形两侧墙，四边形顶棚/底面直接落到底层），大门敞开；内部有一条**石英楼梯**道路，以及一段**用玻璃板单独围起、由石砖楼梯构成的扶梯**。两个出入口一个在场地南侧、一个在北侧，分别朝东、朝西开。
4. **出入口与街面的衔接**：每个出入口比顶层地面**垫高一点**，用**台阶**衔接；大门外左右各一座**石狮子雕像**（成对、对称）。
5. **商业街**（上层）：从出入口楼梯下来先进入商业街——**横向一条**；两侧布置三间店铺，地面铺装完整、收边清楚。
6. **衣服店**：玻璃门；**盔甲架**当模特；**栅栏**当衣杆做展示；店深处有收银柜台与**试衣间**（单独隔断，**旗帜**封门）；店中央留几个**环绕布置的木制楼梯**当座椅。
7. **美食店**：临街**半开口**；入口处一半延伸至店内一半深处，用**玻璃板**隔断出收银柜台与食物制作间；剩余部分用**栏杆 + 木制压力板（或羊毛毯）**当桌子，桌两侧摆**台阶**当座椅；店内桌椅一律靠墙摆放。
8. **珠宝店**：入口起整店地板用**石英台阶**铺满；离墙一两格处挖掉换成**红色混凝土**，其上摆**玻璃块**当柜台；入口处用**玻璃板**隔断，留出至少 **2×3 格**的玻璃块展台，其上方朝外摆**物品展示框**，分别展示**钻石**与**绿宝石**（左右各一）。
9. **商业街两端**：尽头各有**向下直通电影院层的楼梯**（做法参照出入口楼梯）和一个**预留电梯间**（井道；不直通站台层）。
10. **商业街中段**：一侧是连接两个出入口楼梯的**集散平台**；另一侧接**地铁站安检处**。
11. **地铁站顺序**：安检处 → **购票窗口** → **检票口** → **候车大厅**，顺序清楚、全程可走通。
12. **候车大厅**：有 **4 部**下到站台层的**楼梯和电梯**（做法参照出入口设计）。
13. **站台层**（中层）：**密闭**；两侧是**列车轨道**（与站台之间有可辨的安全边界）；站台中央一排**支撑柱**，每根柱朝站台两侧各摆**一排三个台阶**当座椅；从入口楼梯下来的衔接处**往后数格**再摆台阶座椅，不挡人流。
14. **电影院层**（底层）：商业街两端楼梯**直通**；含**购票窗口、零食贩卖窗口、等待大厅**（大厅包含这两种窗口；两个方向的楼梯都先到等待大厅，**不直接进入影院内部**）、**检票口**；检票后进入**廊道**，廊道分别衔接各放映厅。
15. **放映厅**：每个独立厅**高三层**（厅内净高 ≥ 9）；每厅**两个出入口**；座席为**三角台阶延伸式**（台阶当座椅、逐排升高）；**超大荧幕**由黑色混凝土与玻璃**两层**构成，**玻璃层朝放映厅**；厅内用**楼梯**连接不同排/行并与出入口衔接。
16. **连通（硬要求）**：出入口 → 商业街 → 安检 → 购票 → 检票 → 候车大厅 →（4 部楼梯/电梯）→ 站台；商业街两端楼梯 → 电影院等待大厅 → 检票口 → 廊道 → 各放映厅。门洞与通道不填死、无断梯。
17. **对称与节奏**：两个出入口南北对置、朝向相反；每个大门两侧石狮子左右对称；店铺按开间规律排列；路灯等距；不放随机噪声方块。

## 二、forbidden

- 禁 y ≤ 0 的方块（含挖地）：最底层楼面从 y = 1 起（y ≤ 0 不渲染、悬空测量失真）。
- 禁悬空：顶层街面、公园、人行道、马路、荧幕、座椅台阶、支撑柱、石狮子都要有承托；禁整片浮空平台。
- 禁把出入口大门、楼梯、扶梯、检票口、门洞填死；禁断梯、缺级、斜角唯一相接。
- 禁省略点名内饰：三间店铺、站厅、候车大厅、影院等待大厅与放映厅的内饰都要做。
- 禁把石狮子、盔甲架、物品展示框（钻石/绿宝石）、旗帜、压力板/羊毛毯、红色混凝土柜台等点名物件省掉或替换掉。
- 禁大片随机方块噪声；花、灯、展示框按规律或对称布置。
- 禁把三层叠错（电影院必须在底、站台居中、商业街在上、顶层街面在最上）。
- 禁把车站与商业街、影院之间的连通路径做成实墙或死路。

## 四、风格与可观察条款

- 意图：一座把地铁站、电影院、商业街竖着叠起来的**地下综合体**；玻璃、石英、石砖为主材，红混凝土、羊毛毯、旗帜、展示框等做点缀。从上往下看是公园街道，剖开看是三层功能空间。
- 材质建议：玻璃与玻璃板、石英块/石英台阶/石英柱、石砖楼梯、铁栏杆与栅栏、旗帜、盔甲架、物品展示框（钻石/绿宝石）、红色混凝土、羊毛毯、木制压力板、深色橡木、灯/灯笼/海晶灯等。
- 可观察：俯视/斜视能看到三层叠放关系与顶层街面；两个三角柱体入口与石狮子对称；三间店铺可辨识（衣架、餐桌、珠宝柜台）；站台支撑柱与座椅阵列；放映厅台阶座席与双层荧幕（玻璃朝内）。
- 只可观察、不可机械证明：玻璃框架造型是否好看、比例是否协调、店铺摆设是否有生活感、公园是否自然。

## 五、交付与执行

同统一循环（不喂给模型）。

评判要点（给人看，模型看不到）：

- 机械：出入口 → 商业街 → 安检 → 购票 → 检票 → 候车大厅 →（4 部楼梯/电梯）→ 站台全程连通；商业街两端楼梯 → 影院等待大厅 → 检票口 → 廊道 → 各放映厅连通（硬要求，用指定站立点验证，删梯后应到不了）。
- 机械：无悬空（重点查顶层街面、石狮子、荧幕、站台柱、放映厅座席）；没有 y ≤ 0 的实体格。
- 计数：出入口 2、石狮子 4、候车大厅下站台的楼梯/电梯 4、每厅放映厅出入口 2、珠宝店展示框 2（钻石 + 绿宝石）。
- 目测（俯视/斜视）：三层叠放关系可辨；顶层公园→人行道（路灯）→马路的层次；两个入口南北对置、朝向相反。
- 目测（各层内部）：三间店铺的点名内饰；站厅顺序；站台柱与座椅、轨道；影院等待大厅与廊道；放映厅台阶座席与双层荧幕（玻璃层朝内）。
- 若楼梯断开、门洞填死、把点名构件换成别的方块，记为缺陷。
