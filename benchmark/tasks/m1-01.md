# M1-01 农舍 · 田边小谷仓

> task_id: `m1-01` ｜ family: `m1-barn` ｜ split: **m1** ｜ 难度：易（首批第 1 道）
> 单栋、单层、无楼梯；只做外观与可进入，不做内饰（决策 #36）。

## 一、must

1. **单栋单层谷仓**：封闭外墙围合，内部留空，地面层可以站人走动。
2. **落地**：外墙或台基直接落在草地上，整栋无悬空。
3. **大门可进入**：一个长边正中开一扇谷仓大门，净宽 ≥ 3、净高 ≥ 4，门洞贯通墙厚、不填实，人从外面草地能直接走进室内。
4. **双坡屋顶**：屋脊沿长边方向，屋面完整盖住墙顶，四边出檐 ≥ 1 格；两端山墙封闭。
5. **侧窗**：两个长边各至少 2 扇小窗（可装玻璃）。
6. **材质倾向**：墙以木材为主（橡木或云杉木板/原木），墙脚一圈石料（圆石或石砖）勒脚，屋面用与墙不同的深色材质。

## 二、forbidden

- 禁做第二栋建筑、围栏、道路网、树群、水体等扩展场景。
- 禁楼梯、阁楼层、平屋顶。
- 禁把门洞用方块或门填死以致进不去。
- 禁无支撑悬挑：屋面以外不得有孤立悬空块。

## 三、尺寸/规模范围

| 项                 | 范围                 |
| ------------------ | -------------------- |
| 墙体外轮廓         | 长边 11–15、短边 7–9 |
| 墙高（地面到檐口） | 5–7 格               |
| 最高点（屋脊）     | 9–13 格              |
| 实体方块预算       | ≤ 6,000（小体量）    |

## 四、风格与可观察条款

- 意图：**朴素、敦实、一眼看出是谷仓**；大门是正立面的主角。
- 可观察：大门是否居中且走得通、屋脊方向、出檐、勒脚与墙材质分区、窗的分布是否对称。
- 只可观察、不可机械证明：比例是否敦实、材质搭配观感。

## 五、交付与执行

同统一循环（不喂给模型）。

评判要点（给人看，模型看不到）：

- 机械：从大门外草地格能走到室内地面（可进入）；无悬空；墙外轮廓与屋脊高度落在第三节范围内。
- 机械：屋面覆盖整个墙顶并出檐 ≥ 1；屋脊方向与长边一致。
- 目测：大门在长边正中、净宽 ≥ 3；两长边各 ≥ 2 扇窗。
- 目测：木墙 + 石勒脚 + 深色屋面三段材质可读。
- 若模型做了阁楼或内饰，记为偏题但不计硬失败。
