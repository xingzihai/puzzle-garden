# M1-03 商业 · 两层街边商铺

> task_id: `m1-03` ｜ family: `m1-shop` ｜ split: **m1** ｜ 难度：中（首批第 3 道）
> 单栋两层，带一部室内楼梯；只做外观与可进入，不做内饰（决策 #36）。

## 一、must

1. **两层单栋商铺**：外墙围合，内部留空，**两层**，二层有一整块楼板。
2. **一层店面**：临街（南面）一扇店门 + 一大扇橱窗。店门净宽 ≥ 2、净高 ≥ 3，门洞贯通、不填实，从街面能走进一层；橱窗宽 ≥ 5，装玻璃。
3. **店门雨棚**：店门上方一条外挑雨棚，挑出 1–2 格。
4. **楼层可达**：室内一部楼梯（直跑或折返）从一层地面通到二层楼板面，踏步连续、无断梯、无悬空，二层落脚处有净空能站人。
5. **二层开窗**：二层南面至少 2 扇窗，东西两面各至少 1 扇。
6. **坡屋顶**：双坡，屋脊平行于临街面，出檐 ≥ 1 格。
7. **材质分层**：一层与二层外墙用两种可区分的材质（例如一层石砖、二层木板或砖），分界在二层楼板高度附近。

## 二、forbidden

- 禁街道、相邻店铺、招牌文字、树群等扩展场景。
- 禁第三层、阁楼、屋顶露台。
- 禁室外楼梯代替室内楼梯；禁斜角唯一相接或悬空的楼梯。
- 禁把店门填死。

## 三、尺寸/规模范围

| 项                 | 范围                               |
| ------------------ | ---------------------------------- |
| 墙体外轮廓         | 面宽（东西）9–13、进深（南北）9–11 |
| 层高               | 4–6 格                             |
| 墙高（地面到檐口） | 9–13 格                            |
| 最高点（屋脊）     | 13–18 格                           |
| 实体方块预算       | ≤ 12,000                           |

## 四、风格与可观察条款

- 意图：**临街一面是门脸**：一层通透开放（大橱窗 + 雨棚），二层收敛、窗小而齐。
- 可观察：店门是否走得通、橱窗大小、雨棚、楼梯连通、上下两层材质分界、屋脊方向。
- 只可观察、不可机械证明：门脸是否有商铺感、比例与开窗节奏。

## 五、交付与执行

同统一循环（不喂给模型）。

评判要点（给人看，模型看不到）：

- 机械：街面 → 店门 → 一层地面 → 楼梯 → 二层楼板面全程连通（楼层可达，硬要求）。
- 机械：两层楼板层位与层高落在第三节范围；无悬空。
- 目测：南面店门 + 宽 ≥ 5 的玻璃橱窗 + 雨棚；二层南 ≥ 2 窗、东西各 ≥ 1 窗。
- 目测：两层外墙材质可区分，分界在楼板附近；屋脊平行于南面。
- 若楼梯挖穿外墙或挡住窗洞，记为缺陷。
