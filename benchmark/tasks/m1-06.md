# M1-06 航标 · 方形灯塔与守塔人小屋

> task_id: `m1-06` ｜ family: `m1-lh` ｜ split: **m1** ｜ 难度：最难（备用第 3 道）
> 细高方塔 + 螺旋梯登顶 + 相连的守塔人小屋，三部件；只做外观与可进入，不做内饰（决策 #36）。
> 与 F5 观景方塔区别：塔身更细、无中间楼层、顶部为灯室，且带附属小屋。

## 一、must

1. **方形塔身**：外轮廓方形、细高，外墙围合、内部留空；塔身中间不设楼层，只有顶部一层灯室楼面。
2. **登顶**：塔内一部**螺旋楼梯**从塔底地面通到顶部灯室楼面，踏步连续、无断梯、无悬空（硬要求）。
3. **灯室与观景廊**：塔顶灯室楼面向外挑出一圈可站人的观景廊，外沿一圈栏杆无缺口；廊中间一间小灯室，四面装玻璃，可从楼梯口走进灯室、走到观景廊。
4. **灯室屋顶**：攒尖顶 + 顶饰（顶饰须落在尖端上）。
5. **守塔人小屋**：塔脚一侧紧贴一间单层小屋，外墙围合、内部留空，坡屋顶出檐 ≥ 1；小屋朝外开门，门洞贯通、不填实，从草地能走进小屋。
6. **塔屋相通**：小屋与塔身之间有门洞相通，从小屋能直接走进塔底并上梯。
7. **材质分段**：塔身用浅色石料为主，至少一圈与之对比明显的色带（例如红色混凝土或红砖）；灯室玻璃；小屋可用木材或圆石。

## 二、forbidden

- 禁圆形塔身。
- 禁塔身中段加楼层或第二个观景廊。
- 禁码头、礁石、水体、道路网、树群等扩展场景。
- 禁斜角唯一相接或悬空的楼梯；禁观景廊无支撑悬挑（外挑须有台基、楼板或挑梁承托）。

## 三、尺寸/规模范围

| 项                   | 范围                      |
| -------------------- | ------------------------- |
| 塔身外轮廓           | 7–9 × 7–9                 |
| 灯室楼面高度         | 20–28 格                  |
| 观景廊外缘           | 塔身外轮廓每边外挑 1–2 格 |
| 灯室外轮廓           | 5–7 × 5–7                 |
| 最高点（含顶饰）     | 28–38 格                  |
| 守塔人小屋墙体外轮廓 | 7–11 × 5–7，墙高 4–5      |
| 实体方块预算         | ≤ 18,000                  |

## 四、风格与可观察条款

- 意图：**细高挺拔、顶端发亮**：塔身简洁，色带点题，矮小屋衬出塔高。
- 可观察：塔身比例、螺旋梯连通、观景廊栏杆与承托、灯室玻璃、色带、小屋与塔的连接。
- 只可观察、不可机械证明：挺拔感、色带位置是否好看。

## 五、交付与执行

同统一循环（不喂给模型）。

评判要点（给人看，模型看不到）：

- 机械：草地 → 小屋门 → 小屋 → 塔底门洞 → 螺旋梯 → 灯室楼面 → 观景廊全程连通（硬要求）。
- 机械：观景廊栏杆连续无缺口；无悬空（观景廊外挑须有承托）。
- 机械：塔身、灯室楼面高度、最高点落在第三节范围。
- 目测：灯室四面玻璃；至少一圈对比色带；小屋紧贴塔脚且有坡屋顶。
- 若螺旋梯挖穿塔墙或堵住塔屋相通的门洞，记为缺陷。
