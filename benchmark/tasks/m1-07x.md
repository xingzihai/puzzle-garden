### A 设计要求

1. **拉丁十字平面，左右严格对称**：中轴为 x=0，主立面朝南（+z）。从南到北依次为：南立面双塔 → 中殿（两侧各一条侧廊）→ 十字交叉处（东西两翼耳堂）→ 唱诗班席 → 半圆后殿 → 后殿外的放射状小礼拜堂。全部部件以 x=0 镜像对称，东西两半逐格一致（方块也一致）。
2. **台基**：整座教堂落在一圈高 1–2 的台基上，台基外挑 1 格；正门前有踏步从地表登上台基接到门洞。
3. **中殿与侧廊**：中殿外墙高于侧廊；两条侧廊紧贴中殿东西两侧、墙较矮，侧廊屋顶为单坡顶，高侧靠中殿墙。中殿墙在侧廊屋顶以上露出的一段开一排**高侧窗**（尖拱、装彩色玻璃，每个开间一扇，窗底高于侧廊屋面）。中殿与侧廊之间的墙在地面层开一排**尖拱连拱**（每个开间一个，门洞贯通、不填实），从中殿能走进侧廊。
4. **开间节奏**：开间宽 10。中殿每侧 8 个开间；侧廊外墙窗、高侧窗、连拱、扶壁墩都按同一开间排列、逐开间对齐。
5. **侧廊窗与窗棂**：侧廊东、西外墙每个开间一扇尖拱彩色玻璃窗（每侧 8 扇）；侧廊窗与高侧窗都有一圈与墙面不同方块的窗框，窗内有 1 道横向窗棂（石料、栏杆或玻璃板），把窗分成上段尖拱头与下段直身两部分。
6. **扶壁与飞扶壁**：侧廊外墙在相邻两扇窗之间（开间分界处）各立一根扶壁墩，每侧不少于 7 根、间距 10；墩从台基顶起，外凸 3–4 格，顶部高出侧廊檐口。每根扶壁墩顶伸出一道**飞扶壁**（每侧不少于 7 道，东西合计不少于 14 道）——一条从墩顶跨过侧廊屋顶、落到中殿高侧窗之间墙面上的阶梯形或斜向石梁（宽 ≥ 1，两端都与墙或墩实接，不悬空、不穿过窗洞）。
7. **小尖塔（pinnacle）**：每根扶壁墩顶各立 1 座小尖塔（方形底座 + 收细的柱身 + 顶饰，总高 ≥ 4，比墩身窄或带收分）；双塔每座四角的角扶壁顶也各立 1 座。全建筑小尖塔合计不少于 22 座，全部按对称或开间规律布置。
8. **耳堂**：十字交叉处向东、向西各伸出一翼，墙高与中殿相同；两翼端墙（东墙、西墙）各开一扇大尖拱窗或一个圆窗；耳堂与中殿内部相通。耳堂南、北两面墙按同一开间宽 10 开窗，每面不少于 1 扇尖拱彩窗。
9. **唱诗班席与后殿**：交叉处以北延续一段唱诗班席（宽与中殿相同），东西墙按开间宽 10 开尖拱彩窗；北端接半圆形后殿（平面为半圆，曲边朝北）；后殿曲墙上开 3–5 扇等距尖拱彩窗，左右对称。后殿与唱诗班席内部相通。
10. **放射状小礼拜堂**：后殿曲墙外侧贴 3 个小礼拜堂（中轴 1 个、两侧对称各 1 个），每个都是小半圆墙体 + 自己的屋顶，各开 1 扇尖拱窗。外观可辨即可，内部是否与后殿相通不作要求。
11. **南立面与双塔**：南立面左右两座方塔（东西对称），塔身分三层，每座塔四角各一根外凸 1–2 格的角扶壁，沿塔身升到顶层。层与层之间有一圈外凸 1 格的腰线：
    - 底层：朝南开一扇尖拱侧门，可从地表或台基走进塔底；
    - 中层：四面各 1–2 扇窄尖拱窗；
    - 顶层（钟楼）：四面各 1–2 扇更大的尖拱开口，不装玻璃（可留空或装铁栏杆）。
      塔身顶部为**带女儿墙的平台**，平台中央再立一座四坡/攒尖的**尖顶**，尖顶顶端有风向标；尖顶与女儿墙之间留出一圈可站人的走道。
12. **登塔**：至少一座塔（建议两座都做，镜像即可）内部每层有楼板，楼梯（螺旋或折返）从塔底地面依次连到各层楼板，最后通到塔顶平台；踏步连续、无断梯、无悬空（硬要求）。
13. **正门**：两塔之间的中殿南墙为主立面，正中开**尖拱大门**（宽 8、高 12，双开门），门上有铁栏杆装饰。门框至少 2 层、逐层向内退进，外层凸出墙面 ≥ 2 格，用楼梯、墙类等形态方块做出线脚。
14. **玫瑰窗**：大门正上方开一个**圆形玫瑰窗**，直径 15，外框一圈与墙面不同的石料。窗内做放射花瓣状几何图案：
    - 中心为白色或黄色光晕；
    - 花瓣 8 或 16 瓣，从中心向外放射，图案以中心对称；
    - 花瓣之间用窗棂（石料、栏杆或玻璃板）分隔，窗棂条数与花瓣数相同；
    - 染色玻璃颜色合计不少于 5 种（含中心光晕色）。
15. **山墙**：主立面顶部为三角山墙，山墙顶低于两塔的平台。
16. **中央尖塔**：十字交叉处立一座方形尖塔，塔身高出中殿屋脊，再收成高耸的尖顶并带顶饰；它是全建筑最高点，高于双塔尖顶。塔身须落在实体承托上（从地面立起，或落在交叉处的墙体/实心承托上），不悬空。
17. **陡峭屋顶与屋脊收边**：中殿、唱诗班席为南北走向双坡顶，耳堂为东西走向双坡顶，两者屋脊同高、在交叉处相接。屋脊高出檐口不少于该屋顶外宽的 0.6 倍（明显陡于 45°）。中殿、耳堂、唱诗班席的屋脊全长用楼梯和台阶收边。后殿与小礼拜堂用攒尖或四坡顶，均低于中殿屋脊。
18. **檐口线脚**：侧廊檐口高度一圈外凸 1 格的腰线，并在双塔上延续；中殿、耳堂、唱诗班席的高墙檐口各有一道外凸 ≥ 1 格的线脚（飞扶壁落点处可让开）。
19. **可进入**：从广场经正门踏步走进中殿；中殿 → 侧廊、中殿 → 耳堂 → 唱诗班席 → 后殿全程连通，门洞与连拱都贯通、不填实。
20. **南侧广场与石径**：正门前铺一片矩形广场，正门踏步落在广场上；一条宽 10 的石径从广场南缘向南延伸；石径两侧每隔 8 格对称立一盏灯（灯柱 + 灯笼）。广场和石径上不种树。
21. **少量樱花点缀**：广场东、西两侧（广场之外）各 2 棵小樱花树，左右对称（樱花原木树干 + 樱花树叶树冠，可在树下地面铺少量粉色花瓣）；树冠不遮挡正门、玫瑰窗、双塔。

### B 坐标骨架与建造顺序

**总原则**

- 用构件建体量：墙用 `walls`、屋顶用 `roof`、门窗与连拱用 `opening`、楼板用 `floorPlate`、楼梯用 `stair`、踏步用 `steps`、广场用 `paving`。`set` / `box` 只用于构件做不出的细部（扶壁墩、飞扶壁、小尖塔、尖顶、腰线、玫瑰窗花瓣、门）。不要把 `world` 包进自己的类，不要自写合并 box 的逻辑。
- **一切东西的东半边写在 `w.mirror({ axis: 'x', at: 0 }, () => { … })` 里**，西半边由镜像生成。只有横跨中轴的部件（中殿、耳堂、唱诗班席、后殿、主立面、中央尖塔、广场）写在镜像外。扶壁、飞扶壁、侧廊窗的循环**必须**在镜像里，写在镜像外只会建出一侧。
- 坐标：x 东、y 上、z 南（+z）。台基 y1–2，墙底 y = 3，室内站立面 y = 3。
- 尺寸用下面的数字，不要另起一套；先把 B1–B6 的体量跑通（检查执行成功、左右对称 100%、目标都能到），再做 B7 细部。

**B1–B6 骨架（已离线执行通过，可以直接用作第 1 版）**

```ts
/** 东西立面开洞：洞中心的世界 z → opening 的 at（at 相对立面中点、沿 +z）。 */
const atZ = (zc: number, minZ: number, maxZ: number): number => zc - Math.floor((minZ + maxZ) / 2);
const GLASS = ['red_stained_glass', 'blue_stained_glass', 'purple_stained_glass', 'yellow_stained_glass'];
const glass = (i: number): Material => GLASS[i % GLASS.length] as Material;

export default function build(w: World): void {
  const STONE = 'stone_bricks' as Material;
  const DARK = 'polished_deepslate' as Material;
  const LIGHT = 'quartz_block' as Material;
  const ROOF = 'deepslate_tiles' as Material;

  // B1 台基：每个体块一块，承托轮廓 = 体块外轮廓，外挑 1
  w.plinth({ footprint: rect(-24, 0, 24, 99), height: 2, project: 1, material: DARK }); // 中殿 + 侧廊 + 主立面
  w.plinth({ footprint: rect(15, 80, 34, 99), height: 2, project: 1, material: DARK }); // 东塔
  w.plinth({ footprint: rect(-34, 80, -15, 99), height: 2, project: 1, material: DARK }); // 西塔
  w.plinth({ footprint: rect(-60, -30, 60, -1), height: 2, project: 1, material: DARK }); // 耳堂
  w.plinth({ footprint: rect(-15, -76, 15, -31), height: 2, project: 1, material: DARK }); // 唱诗班席 + 后殿

  // B2 中殿：外宽 30（x −15..15），z 0..96，墙高 30（净高 30）
  const nave = w.walls({ footprint: rect(-15, 0, 15, 96), y: 3, height: 30, material: STONE });

  w.mirror({ axis: 'x', at: 0 }, () => {
    // B3 东侧廊：外宽 10（x 15..24），z 0..79，墙高 15；单坡高侧靠中殿（west），坡顶 y21
    const aisle = w.walls({ footprint: rect(15, 0, 24, 79), y: 3, height: 15, material: STONE });
    w.roof({ on: aisle.top, kind: 'shed', high: 'west', peakY: 21, overhang: 1, material: ROOF });
    // 8 个开间，开间中心 z = 5, 15, …, 75；开间分界（扶壁位置）z = 10, 20, …, 70
    const aisleE = aisle.facade('east');
    const naveE = nave.facade('east');
    for (let i = 0; i < 8; i += 1) {
      const zc = 5 + 10 * i;
      // 侧廊窗：净宽 4、净高 10
      w.opening({
        in: aisleE,
        kind: 'window',
        shape: 'pointed',
        width: 4,
        height: 10,
        sill: 2,
        at: atZ(zc, 0, 79),
        fill: glass(i),
        frame: { material: LIGHT },
      });
      // 连拱：中殿东墙地面层，贯通、不填
      w.opening({ in: naveE, kind: 'door', shape: 'pointed', width: 4, height: 9, at: atZ(zc, 0, 96) });
      // 高侧窗：窗底 y22，高于侧廊坡顶 y21
      w.opening({
        in: naveE,
        kind: 'window',
        shape: 'pointed',
        width: 4,
        height: 10,
        sill: 19,
        at: atZ(zc, 0, 96),
        fill: glass(i + 1),
        frame: { material: LIGHT },
      });
    }

    // B4 东塔：外轮廓 20 × 20（x 15..34，z 80..99），3 层 × 层高 16，墙 y3..50
    const tower = w.walls({
      footprint: rect(15, 80, 34, 99),
      y: 3,
      storeys: { count: 3, height: 16 },
      material: STONE,
    });
    const f1 = w.floorPlate({ in: tower.storey(1), material: DARK });
    const f2 = w.floorPlate({ in: tower.storey(2), material: DARK });
    w.opening({ in: tower.facade('south'), kind: 'door', shape: 'pointed', width: 3, height: 5, at: 0 }); // 塔底侧门
    const deck = w.roof({
      on: tower.top,
      kind: 'flat',
      parapet: { height: 1, material: 'stone_brick_wall' },
      material: DARK,
    });
    if (deck.top === undefined) throw new Error('平屋面应返回 top');
    // 塔内折返梯：塔底 → 二层 → 三层 → 塔顶平台（站立面 y52）
    w.stair({
      from: tower.inner,
      to: f1.top,
      at: [18, 84],
      kind: 'switchback',
      facing: 'south',
      material: 'stone_brick_stairs',
    });
    w.stair({
      from: f1.top,
      to: f2.top,
      at: [30, 84],
      kind: 'switchback',
      facing: 'south',
      material: 'stone_brick_stairs',
    });
    w.stair({
      from: f2.top,
      to: deck.top,
      at: [18, 84],
      kind: 'switchback',
      facing: 'south',
      material: 'stone_brick_stairs',
    });
    // 塔顶尖顶：B7 用 spire 范例放在 deck.top.y 上，中心 (24, 89)，半径 ≤ 6，留出走道
  });

  // B5 主立面：中殿南端一道 3 格厚、40 高的立面墙（z 97..99），正门、玫瑰窗开在它的南立面
  const front = w.walls({ footprint: rect(-15, 97, 15, 99), y: 3, height: 40, material: STONE });
  const door = w.opening({
    in: front.facade('south'),
    kind: 'door',
    shape: 'pointed',
    width: 8,
    height: 12,
    at: 0,
    frame: { width: 2, material: LIGHT },
  });
  w.opening({ in: front.facade('north'), kind: 'door', shape: 'pointed', width: 8, height: 12, at: 0 }); // 立面墙内侧也开通
  w.opening({ in: nave.facade('south'), kind: 'door', shape: 'pointed', width: 8, height: 12, at: 0 }); // 中殿南墙开通
  w.opening({
    in: front.facade('south'),
    kind: 'window',
    shape: 'round',
    width: 15,
    height: 15,
    sill: 17,
    at: 0,
    fill: 'white_stained_glass',
    frame: { material: LIGHT },
  }); // 窗底 y20，高于门顶 y15 ≥ 4
  w.steps({ to: door, width: 8, material: 'stone_brick_stairs' });
  w.roof({ on: nave.top, kind: 'gable', ridge: 'z', pitch: 2, overhang: 0, material: ROOF }); // 中殿屋顶；overhang 0，免得撞上立面墙

  // B6 耳堂（x −60..60，z −30..−1）、唱诗班席（z −60..−31）、后殿（z −76..−61），彼此用大门洞连通
  const tr = w.walls({ footprint: rect(-60, -30, 60, -1), y: 3, height: 30, material: STONE });
  w.roof({ on: tr.top, kind: 'gable', ridge: 'x', pitch: 2, overhang: 1, material: ROOF });
  w.opening({ in: nave.facade('north'), kind: 'door', shape: 'pointed', width: 11, height: 20, at: 0 });
  w.opening({ in: tr.facade('south'), kind: 'door', shape: 'pointed', width: 11, height: 20, at: 0 });
  const choir = w.walls({ footprint: rect(-15, -60, 15, -31), y: 3, height: 30, material: STONE });
  w.roof({ on: choir.top, kind: 'gable', ridge: 'z', pitch: 2, overhang: 1, material: ROOF });
  w.opening({ in: tr.facade('north'), kind: 'door', shape: 'pointed', width: 11, height: 20, at: 0 });
  w.opening({ in: choir.facade('south'), kind: 'door', shape: 'pointed', width: 11, height: 20, at: 0 });
  w.opening({ in: choir.facade('north'), kind: 'door', shape: 'pointed', width: 11, height: 18, at: 0 });
  const apse = w.walls({ footprint: rect(-15, -76, 15, -61), y: 3, height: 24, outline: 'apse', material: STONE });
  w.opening({ in: apse.facade('south'), kind: 'door', shape: 'pointed', width: 11, height: 18, at: 0 });
  w.roof({ on: apse.top, kind: 'pyramid', pitch: 1, overhang: 0, material: ROOF }); // 后殿屋顶必须用 on: apse.top，才会跟随半圆轮廓

  // 中央尖塔：塔身从地面立起（x −8..8，z −24..−8），墙高 60，尖顶在 B7
  w.walls({ footprint: rect(-8, -24, 8, -8), y: 3, height: 60, material: STONE });

  // 广场：东西 120、南北 60
  w.paving({ region: rect(-60, 101, 60, 160), material: STONE });
}
```

离线验证这份骨架时测到的、你接手时要知道的几件事：

- 偶数宽的洞（正门宽 8）中心会偏到 x 较小一侧一格（规则见 `opening` 的 `at`），所以"只在一侧的实体"会列出正门两侧各一列；这是题面尺寸决定的，不用处理。连通用的大门洞取奇数宽 11，居中对称。
- 中央尖塔塔身顶部敞口，测量会报"walls#… 上方没有屋面"，B7 放上尖顶后消失。
- 后殿屋顶会报一组"只靠棱角相连"的悬空（屋面薄壳沿半圆曲边的台阶状），这是坡面的正常形态，不用处理。
- 主立面墙北侧有 1 列"上方没有屋面"（立面墙内侧那 1 格），也不用处理。
- `opening` 的 `at`：南北立面沿 +x、东西立面沿 +z，相对**该立面的中点**。东西立面一律用 `atZ(洞中心 z, 墙 minZ, 墙 maxZ)` 换算，不要心算。
- 中殿 `roof` 的 `overhang` 必须是 0（否则出檐会盖到主立面墙上的洞，报"roof 盖到了此前 opening 的洞"）。
- 高侧窗的 sill 是 19（窗底 y22）：sill 再低，窗框会伸进侧廊屋顶。

## 二、forbidden

- 禁地形：丘陵、挖地、y ≤ 0 的任何结构（包括地下墓穴与地下室）；教堂与广场直接建在 y=0 地表之上。
- 禁内饰：长椅、地毯、祭坛、十字架、管风琴、读经台、吊灯、烛台、壁灯、石棺等。
- 禁大片树林、溪流、池塘、石桥、倒木、雾气等扩展场景；樱花树总数不超过 4 棵，不得种在广场或石径上。
- 禁教堂主体变成粉色：樱花木、樱花树叶、粉色花瓣不得成片用在墙体、屋顶或塔身。
- 禁随机方块噪声（随机混入的杂色方块、随机花瓣等）；所有点缀按规律或对称布置。
- 禁圆形塔身；禁日式神社、城堡、宫殿、现代建筑、废墟风格。
- 禁悬空：飞扶壁两端都必须与扶壁墩、墙体实接；尖塔、小尖塔、平台、观景走道要有承托。
- 禁斜角唯一相接或悬空的楼梯；禁室外楼梯代替塔内楼梯。
- 禁把正门、连拱、塔门填死；禁东西两半不对称。
