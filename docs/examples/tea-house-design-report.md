# 溪畔茶亭 · 建筑设计报告（示例 0.1）

> 示例用途：展示交互 agent 应产出的设计报告深度，不是用户确认方案，也不是真实构建任务。
> 坐标约定：x 向东、y 向上、z 向南；1 格 = 1 m；地面 y = 0，台基顶 / F1 楼面 y = 2。
> 方案状态：草案，待用户确认；以下尺寸、材料、家具均为代理建议。

## 0. 一页摘要

- **概念**：一座面向稻田的日常茶亭——低檐、木石、可坐下来的檐下平台。
- **场地**：村口道路北侧，南面开阔稻田；建筑退后道路 3 m，入口从北侧道路进入，转身面向南侧稻田。
- **规模**：主体 10×8 m，F1 室内约 48 m²，檐下平台约 12 m²，最高点约 9 m。
- **主要空间**：主茶室 48 m²（10 座）、柜台 / 储物 8 m²、入口玄关 4 m²、南侧檐下平台 12 m²。
- **结构**：石台基 + 木墙 / 木柱 + 双坡深瓦屋面；跨度 8 m，木梁 + 中柱（或胶合木梁）方案待结构确认。
- **用户必须项**：能看稻田、室内坐 10 人、大屋檐、木石质感、预算克制。
- **代理建议**：南向大窗 + 檐下平台；北侧服务入口；柜台靠西墙；东侧设一个小储物间。
- **未决**：是否需要卫生间；是否需要一个小厨房；稻田是否属于场地内；屋檐 1.2 m 还是 1.5 m。
- **能力边界**：本方案不包含动态电梯、实体盔甲架 / 展示框；室内家具用方块组合近似。

## 1. 项目理解与需求

### 1.1 用户原话（示例）

> 想在村口做一间小茶室，能看稻田，最好有点日式感觉，预算不要太高。室内能坐 10 人，想要大一点的屋檐。

### 1.3 关键澄清

1. 稻田在南侧，场地南边界外；建筑主开口朝南。
2. 用户确认需要柜台和储物，但不需要完整厨房。
3. 用户接受“入口从北侧道路进入，经过玄关转向南侧”的序列。
4. 卫生间未决：首版不设，保留东侧储物间可改卫生间的可能性。

### 1.4 能力边界

- 室内家具用楼梯、半砖、栅栏、压力板、书架、箱子等方块组合，不能生成真实软装模型。
- 灯具用 lantern / chain 近似，不承诺真实照明效果。
- 结构跨度为设计建议，不是结构计算。

## 2. 场地分析

- 场地：约 20×16 m，北侧村道，南侧稻田，东西为低矮院墙 / 邻地。
- 朝向：主立面朝南，争取冬季日照；南侧檐口遮夏季高角度阳光。
- 入口：北侧道路进入，避开稻田一侧的私密视线。
- 排水：屋面雨水向南、北两侧檐口排出，南侧落入碎石带，北侧接道路边沟。
- 室外分区：北侧入口铺装 3×3 m；南侧檐下平台 6×2 m；东侧碎石 / 低植；西侧留 1.5 m 维护通道。
- 视线：从北入口进入，先看到柜台，再转向南侧稻田，形成“收—放”序列。

## 3. 设计概念

**檐下茶事。**

- **低檐**：南侧檐口压低到 3.2 m，檐下平台成为半室外房间；屋檐外挑 1.2–1.5 m，形成可坐的灰空间。
- **木石**：深色石台基、暖木墙、浅石窗框、深瓦屋面；四种明度，避免单色盒子。
- **框景**：南向三樘窗 + 檐下平台，把稻田框进室内；入口压低，进入后抬头看到屋架与南窗。
- **克制**：不做塔、不做第二栋、不做大面积水景；重点在檐口、窗台、门槛、家具与光线。

### 5.2 入口序列

1. 北侧道路 → 1 级踏步 → 北入口门廊（宽 2 m，深 1.5 m）。
2. 推门进入玄关（2×2 m），左手挂衣 / 伞架，正面看到柜台侧面。
3. 玄关右转进入主茶室；抬头看到南向三樘窗与屋架。
4. 主茶室南侧推拉门 / 落地窗 → 檐下平台 → 稻田。

### 5.3 动线与家具

- 主通道：北入口 → 玄关 → 主茶室中央 → 南侧平台，净宽 ≥1.2 m。
- 服务动线：柜台后侧 0.9 m；储物间门 0.8 m；不穿越座位区。
- 座位：南窗下长凳 3 m + 2 把椅子；中央两张 1 m 方桌，各 4 座；西侧柜台前 2 个高凳。
- 柜台：L 形，总长 3.5 m，高 1.0 m；后侧储物架 0.35 m 深。
- 家具不挡门洞、楼梯口（无楼梯）、窗台；南窗下长凳高 0.45 m，低于窗台 0.9 m。

## 7. 结构

- **体系**：石台基 + 木框架 / 木墙混合；四角木柱 + 南侧两根檐柱，减少南墙开窗后的跨度。
- **柱网**：横向 3 跨（x=-5, -1, 1, 5），纵向 2 跨（z=-4, 4）；中柱可隐藏在柜台 / 隔墙内。
- **跨度**：主梁 8 m；若用胶合木 / 钢梁可做；若用普通木梁，建议在 x=0 增设一根中柱或桁架。
- **屋面**：双坡木椽 + 深瓦；檐口设封檐板 / 滴水；屋脊压顶。
- **悬挑**：南侧檐口 1.2 m，由檐柱 + 挑梁支撑；不依赖悬空装饰。
- **基础**：石台基落地，南侧平台由石基 + 木柱支撑，不悬空。
- 本报告不是结构计算；施工前需结构专业确认。

## 11. 场地与景观

- 北侧入口铺装 3×3 m，接道路；1 级踏步，门槛与室内齐平。
- 南侧檐下平台 6×2 m，木 / 石铺装，边缘 1 m 栏杆，中间留 2 m 开口下 2 级台阶到稻田边。
- 东侧碎石带 + 低植（蕨 / 草），不遮挡东窗。
- 西侧 1.5 m 维护通道，放雨水桶 / 储物。
- 不设大面积水景、树阵、第二栋建筑；景观克制，突出稻田。

## 12. 建造顺序

1. 台基：plinth 10×8，外挑 1，石台基；北侧 steps。
2. 墙体：walls 4 高，木墙；开北门、南窗、东窗、北高窗、储物门。
3. 屋面：gable roof，脊沿 x，pitch 0.75，overhang 1.2–1.5；封檐板 / 屋脊。
4. 门窗：opening + frame + fill；门扇写 opening 层；窗台 / 窗楣。
5. 室内：floorPlate / 地毯；柜台、长凳、桌、椅、书架、储物。
6. 灯具：chain + lantern；入口 / 桌面。
7. 场地：北入口铺装、南平台、台阶、碎石带、低植。
8. 自查：check_code 看悬空 / 可达 / 夹层；view_building 看南立面、入口、檐下、室内（若视角支持）。

## 14. 自由发挥范围与冲突处理

- **不可改**：单栋、南向看稻田、室内 10 座、柜台 + 储物、北侧入口、大屋檐、木石基调。
