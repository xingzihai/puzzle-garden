# F6 多栋院落 · 验证题：三栋带连廊

> task_id: `f6-crt-val` ｜ family: `f6-crt` ｜ split: **val** ｜ status: **新写、不抄开发题参数**
> 与开发题 `f6-crt-dev`（2 栋小院）的差异：**3 栋 + 连廊 + 内院**，布局更复杂。**调参后即降为调优集。**

## 一、must
1. **3 栋**功能相异建筑（正房 + 两厢/一廊一房），主次分明、体量不等。
2. **连廊**至少连接其中 2 栋，连廊有柱与顶，转折处闭合。
3. **内院**由三栋与院墙/连廊围合，院内铺装可通行。
4. 院墙上 **1 处门楼**为主入口，门楼高于普通院墙。
5. 三栋坡屋顶朝向/高度不同，形成可读天际线。
6. 院内外高差自然过渡，无外漏。

## 二、forbidden
- 禁 4 栋及以上、禁网格化街区。
- 禁三栋做成相同复制体。
- 禁连廊中途断裂/无顶/无支撑。
- 禁树木成林遮挡主体。

## 三、尺寸/规模范围
| 项 | 范围 |
| --- | --- |
| 地块 | 约 40–46 × 32–38 |
| 单体数量 | 3 栋 + 1 连廊 |
| 单栋高 | 8–13 格 |
| 院墙高 | 2–4 格 |
| 实体方块预算（全场） | ≤ 55,000 |
| building seed | 受控 |

## 四、风格与可观察
- 意图：**围合 + 连廊流线 + 主次天际线**。
- 可观察：三栋主次比例、连廊连接与支撑、门楼焦点、内院围合、屋顶高低关系。
- 只可观察：院落氛围、轴线。未校准项不冒称机械。

## 五、执行
同统一循环。**与开发题不同**：栋数与连廊带来更多接口/流线挑战。
