# F2 住宅 · 验证题：坡地两层住宅

> task_id: `f2-res-val` ｜ family: `f2-res` ｜ split: **val** ｜ status: **新写、不抄开发题参数**
> 与开发题 `f2-res-dev`（单层小屋）的差异：**2 层 + 坡地适应 + 可走楼梯**。**调参后即降为调优集。**

## 一、must
1. **两层**住宅，一层嵌入坡地/设高差基座，二层体量比一层内收 ≥1 格。
2. **内部楼梯从一层可走到二层**（相邻踏步面相邻、无断续；判据同 `stairWalkability`）。
3. 一层有**主入口 + 门廊**；二层有外挑**阳台/平台**（有栏杆或矮墙）。
4. 每层至少 2 处外窗；窗框材质与墙区分。
5. 双坡或四坡屋顶，屋脊方向明确，出檐 ≤2 格。
6. 基础/挡土墙随坡地高差自然过渡，不突然截断。

## 二、forbidden
- 禁三层及以上；禁悬空阳台无支撑。
- 禁把楼梯做成斜向唯一相接的断梯。
- 禁地下室（本验证题不含）。

## 三、尺寸/规模范围
| 项 | 范围 |
| --- | --- |
| 主体占地 | 11–14 × 8–11 |
| 最高点 | 16–22 格 |
| 层高 | 6–9 格 |
| 实体方块预算 | ≤ 20,000 |
| building seed | 受控 |

## 四、风格与可观察
- 意图：**竖向分层 + 坡地嵌入 + 阳台焦点**。
- 可观察：两层体量收进、楼梯可达性（工程硬判）、阳台栏杆、门窗节奏、坡地衔接。
- 只可观察：居住感、明度层次。未校准项不冒称机械。

## 五、执行
同统一循环。**与开发题不同**：多层 + 可走楼梯 + 坡地，检验跨层与场地能力。
