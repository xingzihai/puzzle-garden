# F4 教堂或礼拜堂 · 验证题：带侧廊的小教堂

> task_id: `f4-chu-val` ｜ family: `f4-chu` ｜ split: **val** ｜ status: **新写、不抄开发题参数**
> 与开发题 `f4-chu-dev`（单塔中型礼拜堂）的差异：**双侧廊 + 玫瑰窗 + 无高塔**，横向展开。**调参后即降为调优集。**
> 尺寸为**中型上限**，仍远小于旧 `task-church` 的百万体素场景。

## 一、must
1. **中殿 + 双侧廊**（每侧宽 3–5 格），侧廊低于中殿、屋面分层。
2. 中殿与侧廊之间**柱列/券洞**成节奏（每 4–5 格）。
3. 主立面中央**尖拱门**（净宽 4–6、净高 7–9）+ 上方**圆形玫瑰窗**（直径 5–7）。
4. **半圆后殿**带 3–5 扇尖拱彩窗。
5. 中殿内**一条可攀登楼梯通往屋顶/阁楼**（硬要求）。
6. 深色坡屋面，侧廊屋面与中殿屋面交接收头清楚，**无高塔**。

## 二、forbidden
- 禁百万体素级环境；实体方块预算硬上限见三。
- 禁高耸尖塔（本验证题刻意不设塔，检验无塔构图）。
- 禁悬空碎块、禁无收口的屋面—墙断裂。

## 三、尺寸/规模范围
| 项 | 范围 |
| --- | --- |
| 中殿+侧廊总占地 | 长 22–28 × 宽 16–20 |
| 最高点（屋脊） | 16–22 格 |
| 柱列/券洞 | 4–5 格间距 |
| 实体方块预算 | ≤ 55,000（中型上限） |
| building seed | 受控 |

## 四、风格与可观察
- 意图：**横向展开、侧廊光影、券窗节奏**；尖拱语言统一。
- 可观察：中殿—侧廊体量层次、柱列节奏、玫瑰窗居中、后殿收尾。
- 只可观察：神圣感、明暗层次。未校准项不冒称机械。

## 五、执行
同统一循环；地穴/管风琴不要求。
