# F3 现代商业或工作室 · 验证题：大跨街角商业

> task_id: `f3-stu-val` ｜ family: `f3-stu` ｜ split: **val** ｜ status: **新写、不抄开发题参数**
> 与开发题 `f3-stu-dev`（14×10 小工作室）的差异：**大跨 + 幕墙 + 挑空**，尺度约 2.5 倍。**调参后即降为调优集。**

## 一、must
1. 单层**大跨空间**（无内柱或仅 2 根内柱），净跨 ≥ 16 格。
2. 街角两面为**大面积幕墙/水平带窗**，分格节奏可读（竖向或横向）。
3. 明确**入口大堂**：主入口 ≥3 格净宽，有雨棚或门头。
4. **平屋面**有完整女儿墙/收边，压在外墙或周边柱梁上。
5. 屋顶局部可退台设小平台（可选）。
6. 材料分层：主体浅色石/混凝土 + 深色金属框 + 玻璃。

## 二、forbidden
- 禁内柱密排破坏大跨；禁多层斜屋顶。
- 禁外墙做成无分格的一整面白盒。
- 禁平屋顶裸露无收口。
- 禁第二栋建筑。

## 三、尺寸/规模范围
| 项 | 范围 |
| --- | --- |
| 主体占地 | 24–30 × 16–20 |
| 最高点 | 12–16 格 |
| 净跨 | ≥ 16 格 |
| 实体方块预算 | ≤ 35,000 |
| building seed | 受控 |

## 四、风格与可观察
- 意图：**大跨体量 + 幕墙分格 + 街角入口**。
- 可观察：跨体完整性、幕墙分格节奏、平顶收边、入口可辨、两街立面差异。
- 只可观察：现代感、通透感。未校准项不冒称机械。

## 五、执行
同统一循环；内饰/室内照明不要求。
