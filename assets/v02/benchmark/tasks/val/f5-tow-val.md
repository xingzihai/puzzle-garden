# F5 塔楼 · 验证题：多层钟塔

> task_id: `f5-tow-val` ｜ family: `f5-tow` ｜ split: **val** ｜ status: **新写、不抄开发题参数**
> 与开发题 `f5-tow-dev`（15×15 观景方塔）的差异：**更细 + 钟面 + 钟室 + 收分**。**调参后即降为调优集。**

## 一、must
1. 塔身方正，外轮廓 **9×9–11×11**，总高 **30–38 格**，分 **3 段**（基座/钟室/顶冠）。
2. **钟面**：至少一面有一个圆形或方形钟面（尺寸 5×5–7×7），以对比色可读。
3. **钟室**（belfry）：上部开敞券窗或百叶，四面可辨。
4. **可攀登楼梯**从地面通到钟室层（硬要求，无断梯）。
5. 顶部**收分**（逐层内收）后加尖顶或垛口，有一处顶饰。
6. 沿高度有**腰线/分层**，材质下重上轻（石基座 → 石/砖身 → 顶冠）。

## 二、forbidden
- 禁斜角唯一相接/悬空楼梯。
- 禁钟面用纯色实心马赛克充数（须有指针/刻度意图）。
- 禁把塔做成无分层的直筒。
- 禁第二塔。

## 三、尺寸/规模范围
| 项 | 范围 |
| --- | --- |
| 塔身占地 | 9×9–11×11 |
| 总高 | 30–38 格 |
| 分段数 | 3 |
| 实体方块预算 | ≤ 16,000 |
| building seed | 受控 |

## 四、风格与可观察
- 意图：**竖向分段 + 钟面焦点 + 上部收分**。
- 可观察：分段比例、钟面可读、券窗节奏、收分与顶冠、楼梯可达性（工程硬判）。
- 只可观察：地标感、细节节奏。未校准项不冒称机械。
