# F1 亭廊 · 验证题：临水折廊

> task_id: `f1-pav-val` ｜ family: `f1-pav` ｜ split: **val** ｜ status: **新写、不抄开发题参数**
> 与开发题 `f1-pav-dev` 的差异：**长条形 + 柱列节奏 + 折线**，不是紧凑单亭。**仅用于选择/对照，调参后即降为调优集。**

## 一、must
1. **折廊**：由 3 段直线段折成（夹角 90°–135°），总长 24–32 格，宽 4–6 格。
2. 柱列节奏：沿廊身每 3–4 格一对檐柱，柱径 1 格。
3. 沿廊**一侧**开敞（临水），另一侧设坐凳栏杆或半墙。
4. 连续**坡屋面**覆盖整条折廊，转折处屋面闭合、无露缝。
5. 两端各一处出入口，接贴地铺装。
6. 台基比柱网外挑 1 格，高 1–2 格。

## 二、forbidden
- 禁做成单亭或封闭建筑；禁第二层。
- 禁折角处屋面断裂/悬空。
- 禁与水体交叉外漏（若做水，水面不得穿结构）。

## 三、尺寸/规模范围
| 项 | 范围 |
| --- | --- |
| 总长 | 24–32 格 |
| 廊宽 | 4–6 格 |
| 最高点 | 7–10 格 |
| 实体方块预算 | ≤ 18,000 |
| building seed | 受控 |

## 四、风格与可观察
- 意图：**线性节奏 + 折线转折的完整性**。
- 可观察：柱距序列、屋面连续、开敞/围合对比、出入口位置。
- 只可观察：轻盈感、比例。未校准项不冒称机械。

## 五、执行
同统一循环。**与开发题不同**：检验模型是否能在长向连续构件上保持节奏与屋面闭合。
