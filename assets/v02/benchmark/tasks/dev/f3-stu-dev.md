# F3 现代商业或工作室 · 开发题：现代街角工作室

> task_id: `f3-stu-dev` ｜ family: `f3-stu` ｜ split: **dev** ｜ status: **规范冻结，正文可调参**
> 复用来源：`v0.2beta/benchmark/exterior/modern-corner-studio-task.md`（14×10、≤12 格、平顶）。
> 正式化，尺寸一致；**非**模型成品、不冒充 owner 认可。

## 一、must
1. 主体为**小型现代工作室**，**平屋面**或局部平缓退台。
2. 允许两层体块错位，但须明确**一个主入口**。
3. 至少 **2 个位置合理、从外面可辨认清**的窗洞。
4. 屋顶有**完整收边**并压在外墙/柱梁上。
5. 材料以浅色石材/混凝土为主，木/深色金属作次框架；外墙不得是一张无层次白盒子。
6. 入口接一小段**贴地铺装**。

## 二、forbidden
- 禁多层斜屋顶、禁把所有外墙做成同一平面无层次。
- 禁道路网/树群/水体/第二栋房屋。
- 禁无收口的平屋顶裸露边。
- 禁发光效果当结构。

## 三、尺寸/规模范围
| 项 | 范围 |
| --- | --- |
| 主体占地 | 13–15 × 9–11 |
| 最高点 | ≤ 12 格 |
| 层数 | 1–2 层错位 |
| 实体方块预算 | ≤ 12,000 |
| building seed | 受控 |

## 四、风格与可观察条款
- 意图：**水平体块 + 深浅节奏 + 幕墙分格**；现代、克制、明度对比可读。
- 可观察：主次体量比例、立面门窗深浅节奏、平顶与墙衔接、材料分区、入口铺装、各立面有无断裂/遮挡。
- 只可观察：现代性、精致度。未校准项不冒称机械。

## 五、执行
同统一循环；内部楼梯/房间/内饰/室内照明不作要求。
