# F4 教堂或礼拜堂 · 开发题：中型小礼拜堂

> task_id: `f4-chu-dev` ｜ family: `f4-chu` ｜ split: **dev** ｜ status: **规范冻结，正文可调参**
> 复用来源：`v0.2beta/benchmark/task-church.md`（拉丁十字大体量，占地 120×180、尖塔 96）。
> **重要更正**：本开发题**主动缩到中型**（用户口径「教堂中型非百万体素」），不复用旧题的超大体量；
> 保留「中殿 + 单塔 + 半圆后殿 + 入口塔」的家族能力点。**非**模型成品、不冒充 owner 认可。

## 一、must
1. **中殿**（长方形主空间）+ **单座钟塔/尖塔** + **半圆后殿**三段清晰层次。
2. 主立面中央**尖拱大门**（净宽 4–6、净高 7–9），上方或正立面有一处**圆形玫瑰窗**（直径 5–7，彩色玻璃）。
3. 中殿两侧或单侧**券洞/侧廊**，券窗成节奏。
4. 塔内或中殿内**有一条从地面通往塔顶/阁楼的可攀登楼梯**（硬要求，判据见 `stairWalkability` 口径）。
5. 屋顶为**深色坡屋面**，有连续屋脊；屋面与塔交接有收头。
6. 材质以石为主，少量木/彩玻璃点缀；不得整栋变粉。

## 二、forbidden
- 禁百万体素级大场景；**实体方块预算硬上限见三**。
- 禁樱花林/广场/小溪等大面积环境扩展（本开发题只看建筑本体 + 紧邻地面）。
- 禁结构悬空碎块；禁把玫瑰窗做成实心马赛克而无透光意图。
- 禁无收口的塔—屋面断裂交接。

## 三、尺寸/规模范围（中型）
| 项 | 范围 |
| --- | --- |
| 中殿占地 | 长 18–24 × 宽 10–14 |
| 最高点（尖塔） | 22–28 格（**远小于旧题 96**） |
| 塔基占地 | 6–8 × 6–8 |
| 层数 | 中殿 1 层 + 阁楼/塔 2–3 层 |
| 实体方块预算 | ≤ **40,000**（中型硬上限） |
| building seed | 受控 |

## 四、风格与可观察条款
- 意图：**石构庄重、纵向主导、券窗节奏**；尖拱语言统一。
- 可观察：中殿—塔—后殿层次、玫瑰窗位置居中、屋面与塔交接、入口辨识。
- 只可观察：神圣感、精致度、材质协调。未校准项不冒称机械。

## 五、执行
同统一循环。内部陈设/管风琴/地穴**本开发题不要求**；塔顶可攀登为硬要求。
