# F5 塔楼 · 开发题：观景方塔

> task_id: `f5-tow-dev` ｜ family: `f5-tow` ｜ split: **dev** ｜ status: **规范冻结，正文可调参**
> 复用来源：`v0.2beta/benchmark/task-tower.md`（15×15、约 40 高、4 层、螺旋梯可登顶）。
> 尺寸一致；**非**模型成品、不冒充 owner 认可。

## 一、must
1. 方形塔身，外轮廓约 **15×15**，地面到塔顶约 **40 格**，共 **4 层**（每层楼板，层高约 9）。
2. **可攀登螺旋楼梯**：从地面一层通到顶层观景台，相邻踏步面相邻，**无断梯/悬空**（硬要求）。
3. 底层南面**券洞（拱门）**，净宽约 5、净高约 7，券顶收口。
4. 顶层观景台外沿一圈**栏杆无缺口**。
5. 每层四面各开一扇窗（共 12 扇）。
6. 塔顶**攒尖顶 + 顶饰**。
7. 材质分层：下两层石砖系、上两层深色橡木系、顶深板岩砖。

## 二、forbidden
- 禁斜角唯一相接/悬空楼梯；禁无收口券洞。
- 禁顶饰落在攒尖尖端之外（会判悬空）。
- 禁在塔体上叠第二座塔或扩展成大场景。

## 三、尺寸/规模范围
| 项 | 范围 |
| --- | --- |
| 塔身占地 | 13–17 × 13–17 |
| 塔体高度 | 35–48 格 |
| 楼层层距 | 6–12 格 |
| 实体方块预算 | ≤ 20,000 |
| building seed | 受控 |

## 四、风格与可观察条款
- 意图：**竖向统一、材质分层可读、顶收束**。
- 可观察：塔身比例、楼梯可达性（工程硬判）、券洞/栏杆/窗、材质带。
- 只可观察：雄壮感、细节节奏。未校准项（券洞/开窗检测器）不冒称机械。

## 五、执行
同统一循环；地形自然过渡为草地，不突然截断。
