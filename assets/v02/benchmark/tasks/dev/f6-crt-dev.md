# F6 多栋院落 · 开发题：两栋小院

> task_id: `f6-crt-dev` ｜ family: `f6-crt` ｜ split: **dev** ｜ status: **规范冻结，正文可调参**
> 复用来源：**无旧题**（现 `v0.2beta/benchmark/` 无多栋院落任务）→ 本开发题**新写**，按用户口径「院落先小型 2–3 栋」。
> **非**模型成品、不冒充 owner 认可。

## 一、must
1. **2 栋**功能相异的小体量建筑（如正房 + 厢房/门房），主次分明。
2. **院墙围合**，墙上有 **1 处门洞/门楼** 作为主入口。
3. 两栋之间/沿墙有 **可通行的院内铺装**，院内外地面高差不突然截断。
4. 各栋自身有可读的坡屋顶（双坡或四坡），屋面与墙、与院墙交接有收头。
5. 沿主入口方向有**入口轴线**可读（门楼 → 主房入口）。

## 二、forbidden
- **禁 4 栋以上、禁大型宫城/街坊网格**（先小型）。
- 禁把两栋做成完全相同的复制体（须主次有别）。
- 禁无收口的单体—院墙断裂交接。
- 禁树木成林遮挡主体（可少量点景）。
- 禁结构悬空碎块。

## 三、尺寸/规模范围
| 项 | 范围 |
| --- | --- |
| 地块 | 约 30–36 × 26–32 |
| 单体数量 | 2 栋 |
| 单栋占地 | 8–14 × 7–10，高 8–12 格 |
| 院墙高 | 2–4 格 |
| 实体方块预算（全场） | ≤ 30,000 |
| building seed | 受控 |

## 四、风格与可观察条款
- 意图：**围合、主次、轴线**；院墙与单体风格统一（木石/砖石择一）。
- 可观察：两栋主次与比例、院墙—门洞—连接、沿街/内院立面差异、铺装围合。
- 只可观察：院落氛围、精致度。未校准项不冒称机械。

## 五、执行
同统一循环；本开发题先做 2 栋，3 栋留给验证/密封题。
