# F2 住宅 · 开发题：村口木石小屋

> task_id: `f2-res-dev` ｜ family: `f2-res` ｜ split: **dev** ｜ status: **规范冻结，正文可调参**
> 复用来源：`v0.2beta/benchmark/exterior/village-cottage-task.md`（12×8、9–11 格、单层）。
> 正式化，尺寸一致；**非**模型成品、不冒充 owner 认可。

## 一、must
1. 单层**木石结构**：浅石基座 + 木墙体 + 深色双坡屋顶，三者分区清楚。
2. 正面有明确**门**；至少 **2 处**从外面看得清的窗洞。
3. **连续屋脊**的双坡屋面，斜面与外墙直接衔接。
4. 入口前 **2–4 格深**贴地铺装。
5. 檐口不得又厚又宽盖住整面墙。

## 二、forbidden
- 禁地下室、禁夹层、禁塔楼。
- 禁多层金字塔顶、禁屋檐完全遮墙。
- 禁树林/池塘/道路网/人物/第二栋；场景只此屋 + 紧邻铺地。
- 禁以氛围灯伪装结构。

## 三、尺寸/规模范围
| 项 | 范围 |
| --- | --- |
| 主体占地 | 11–13 × 7–9 |
| 最高点 | 9–11 格 |
| 檐口外挑 | ≤ 2 格 |
| 实体方块预算 | ≤ 6,000 |
| building seed | 受控 |

## 四、风格与可观察条款
- 意图：**干净、克制、明度分层**（浅基座 / 中木墙 / 深屋面）。
- 可观察：墙窗与入口、屋面斜率与墙体连接、材料分区、铺地是否克制。
- 只可观察：比例协调、材质真实观感。未校准项不冒称机械。
