# F1 亭廊 · 开发题：溪畔茶亭

> task_id: `f1-pav-dev` ｜ family: `f1-pav` ｜ split: **dev** ｜ status: **规范冻结，正文可调参**
> 复用来源：`v0.2beta/benchmark/exterior/tea-pavilion-task.md`（外观对照小茶亭，13×11、9–12 格）。
> 本文件是对该路径的**开发题正式化**，尺寸与旧题一致；**不是**模型成品、不冒充 owner 认可。

## 一、must（硬要求，逐条可在图上指认）
1. 主体为**开放亭**：至少 4 根可辨认角柱承起屋顶，柱间除坐凳栏杆外通透。
2. **抬高的石台基**：高于草地面 1 格，台基向外挑出柱网 ≥1 格。
3. **明确入口**：南向或临水一面有一处 ≥2 格净宽的上台踏步。
4. **完整坡屋顶**：四坡或攒尖，有可读檐口收头；屋顶四边均盖过柱网（出檐 ≥1 格）。
5. 一处**克制的木/石材质分区**（石基座 + 木柱梁 或反之）。
6. 亭前一小段**贴地铺装**与踏步相接。

## 二、forbidden（禁止项）
- 禁大块无意义封墙（不得做成封闭小屋）。
- 禁无支撑悬挑：柱外不得有孤立悬空屋面（合法阶梯除外）。
- 禁多层斜屋顶叠罗汉、禁第二栋建筑、禁道路网/树群/水体等扩展场景。
- 禁把发光/氛围当结构：内部灯饰不进本外观判据。

## 三、尺寸/规模范围
| 项 | 范围 |
| --- | --- |
| 主体占地 | 长边 12–14、短边 10–12 |
| 最高点（含顶饰） | 9–12 格 |
| 台基外挑 | 1–2 格 |
| 柱距 | 3–5 格，四柱或六柱 |
| 实体方块预算 | ≤ 8,000（小体量） |
| building seed | 受控，见 `seeds/building-seeds.json` |

## 四、风格与可观察条款（非审美真值）
- 风格意图：**轻、透、有檐**；柱网节奏均匀，屋顶与柱网相称。
- 可观察：主体是否完整、屋顶是否压在柱梁上、台基与地面是否衔接、入口是否可辨。
- 只可观察、不可机械证明：比例协调、精致、材质观感。
- 未校准项**不冒称机械**（见 `critical-clauses.json` 中 `thresholdStatus`）。
