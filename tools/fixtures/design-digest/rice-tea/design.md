# 稻田茶亭

- 方案：scheme-tea v1
- 状态：待评审
- 范围：外观 + 完整室内（主要空间、家具、楼层与固定家具）
- 概念：北侧村道进入，穿过柜台后转向南侧稻田；压低檐口，让檐下平台成为日常停留的灰空间。
- 来源需求图：req-tea v1

## 项目概念

北侧村道进入，穿过柜台后转向南侧稻田；压低檐口，让檐下平台成为日常停留的灰空间。

## 用户需求与来源

- 需求图：req-tea v1
- 摘要：村口小型茶室，能看稻田，木石质感，预算克制。

- [必须 / 用户 / 已确认] 提供路人喝茶与短暂停留的室内空间。；原话：“想在村口做一间小茶室，路过的人能进来坐坐。”
- [必须 / 用户 / 已确认] 南向设置主要开口与檐下平台，能看到稻田。；原话：“稻田在南边，最好一抬头就能看见。”
- [应当 / 用户 / 已确认] 室内能容纳约十人同时喝茶。；原话：“室内能坐十个人左右。”
- [应当 / 用户 / 已确认] 控制体量与装饰，不把茶室做成旅游景点。；原话：“别太像旅游景点，预算不要太高。”
- [应当 / 用户 / 已确认] 入口侧需要柜台与少量储物。；原话：“需要一个小柜台，能放点东西。”

### 偏好

- [style / strong / confirmed] 木、石、纸感，接近日式但不要符号化。

### 约束

- [budget / 硬约束] 实心方块预算不超过两万。（20000 blocks）
- [forbidden / 硬约束] 不要做成旅游景点式的售票亭。

## 设计决策

- [用户确认 / confirmed] 看景方向：主要开口与檐下平台朝南。（理由：稻田在南侧，且南向采光更稳定。）
- [代理建议 / confirmed] 屋面形式：双坡屋面，南侧檐口压低。（理由：与村居尺度一致，深檐形成可停留的灰空间。）
- [代理建议 / confirmed] 室内范围：完成喝茶区、柜台与入口三个主要室内空间的家具、灯具与地面材质。（理由：小型建筑以室内体验为核心；在克制预算内优先保证主要空间完整。）
