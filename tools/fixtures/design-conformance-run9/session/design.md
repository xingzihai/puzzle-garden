## 设计决策

- [用户确认 / proposed] 单一主厅：建筑外轮廓 10m×8m 内仅设一间 8m×6m 净空主厅，无任何隔墙与隔间。（理由：满足 48㎡ 净面积与全部功能集中于同一空间的要求，避免门厅、走廊与操作间。）
- [用户确认 / proposed] 单层无夹层：整栋单层，层高 4m，不设楼梯、二层或夹层，无地下空间。（理由：遵循单层矩形茶亭定位，控制体量与方块用量。）
- [用户确认 / proposed] 北墙西段入口：北墙西段开 2m 净宽门洞（kind=opening、role=entrance、offset 1、宽 2、高 2），无玻璃门扇与台阶，直线连通北侧村道。（理由：入口对应村道，门洞直接开敞，门内留 1m 净空带不摆家具。）
- [用户确认 / proposed] 南墙唯一大窗：南墙只设一条 4m 宽窗，窗台 1m、窗高 2m、洞顶 3m，以上留 1m 过梁。（理由：把南侧溪景作为室内唯一对外画面，1m 墙深形成深窗套。）
- [用户确认 / proposed] 1m 厚外墙：外墙统一 1m 厚，石基座仅作墙下防潮垫层不外挑，门洞处室内外地面齐平。（理由：深墙形成门窗深度，同时不产生门厅或平台。）
- [用户确认 / proposed] 材料与屋面：石基座、清水木墙木柱、深瓦双坡屋面，东西向屋脊，坡度约 25°，仅短出檐。（理由：保持材料本色与乡土朴素气质，形式靠体量、材料与洞口表达，不做装饰构架。）
- [用户确认 / proposed] 固定家具与照明布置：4m×2m 长桌长边沿东西向贴东墙（wall east offset 4，x7..11、z5..7）；北凳 4×1 贴北墙（wall north offset 7，x7..11、z3..4）、南凳 4×1 贴南墙（wall south offset 7，x7..11、z8..9），以 5+5 表达十座，删除两件 chair 坐垫；2m×1m 柜台贴西墙中段（wall west offset 4，x3..4、z5..7，不占东南角）；两盏吊灯分挂北、南墙墙位。（理由：长桌与两条长凳形成南北对坐的正交茶席，柜台收在西墙不干扰南向视线；家具全部靠墙，中央与门侧保持通透。）
- [用户确认 / proposed] 门内 1m 净空带：北凳整体东移至 x7..11、z3..4，完全位于门洞 x3..5 东侧；门洞内侧 1m 进深（x3..5、z3..4）内不放任何家具；两盏吊灯同步改锚南、北墙以避让东移的长凳。（理由：上一版北凳压住门洞造成 door-clearance-1m 真实冲突，本次定向修订清除该冲突，同时不改变门洞尺寸、位置与入口识别方式。）
- [代理建议 / proposed] 方块用量控制：以 1m 厚墙体、石基座与双坡屋面为主要用量，家具与场地收边克制；删减两件坐垫家具并减少吊挂点。（理由：保持总量在 20000 方块以内。）
