# 村口溪边茶亭（方案 v2）

## 一、需求与设计意图

- 项目：村口溪边茶亭（方案 scheme-draft v2）。
- 交付范围：外观 + 完整室内（主要空间、家具、楼层与固定家具）。
- 设计依据：design.md 是用户确认的方案全文；本简报把它编译成构建要求，build-spec.json 是同一方案的机器视图。
- 优先级：先满足第四节必须项与机器约束，再做形式、材质与细部；不得用体量或装饰替代必须项。
- 规模：建筑范围 x [2, 12) · y [1, 5) · z [2, 10)；场地范围 x [0, 14) · y [0, 8) · z [0, 12)。

## 二、禁止项与边界

- 不得改变已确认方案的主要布局、层数、外部尺寸、层高、入口位置、屋面形式和主要材质
- 不得增加第二栋主体建筑、城市级场景或超出方案范围的体量
- 不得承诺或建造当前 World API 不支持的实体物件、动态电梯、完整地下空间展示
- 不得自行删除或替换用户点名的必须项；无法实现时停止并报告冲突
- 禁止任何隔间、隔墙、门厅、走廊、操作间、设备间与厨房。
- 禁止檐下平台、露台、台阶、坡道及任何室外分区；屋面只做出檐。
- 禁止招牌、售票窗口与装饰性构架。
- 柜台不设水槽、热水与上下水点位，不预留机电。

## 四、验收与自由发挥

### 必须项（逐条核对）

- [ ] req-teahouse-program：在村口溪边新建一座茶亭，作为村口公共小建筑供歇脚饮茶使用。
- [ ] req-outer-10x8：建筑外轮廓为 10m×8m 的矩形体量，不得超出。
- [ ] req-single-storey：整栋为单层，无楼层、无楼梯、无地下空间。
- [ ] req-no-mezzanine：不加二层，也不做夹层（不得以夹层方式增加使用面积）。
- [ ] req-single-hall：整栋只有一间完整主厅，就座、饮茶、备茶、观景等全部功能集中在同一空间内。
- [ ] req-no-partitions：不设玄关、门厅、走廊、卫生间、储藏间、操作间、设备间、厨房或任何隔间，室内不出现任何分隔墙。
- [ ] req-interior-8x6：室内净尺寸 8m×6m，净面积 48㎡。
- [ ] req-wall-thick-1m：外墙厚度 1m，形成较深的门窗洞口，但不因此产生门厅或隔间。
- [ ] req-door-north-west：北墙西段直接开门，门洞净宽 2m，直接连通室外北侧村道，中间不设玄关或门厅。
- [ ] req-door-clear-1m：门内侧保留 1m 宽的空地（门内进深 1m 的净空带），该处不摆放家具。
- [ ] req-window-south-4m：南墙只做一条 4m 宽的大窗用于观看南侧溪流，南墙无其他洞口。
- [ ] req-window-dim：窗台高 1m、窗高 2m，洞口顶位于室内地面以上 3m。
- [ ] req-no-glass-door：南墙不做落地门或落地窗，室内外进出仅通过北门。
- [ ] req-no-outdoor-zone：不做檐下平台、露台、台阶或任何室外分区，场地不新设可停留的室外地面（无铺装平台、无檐廊、无庭院、无入口铺装带）。
- [ ] req-no-steps：入口不设台阶、不设坡道；室内地面与室外地面齐平，经门洞直接连通村道。
- [ ] req-long-table：主厅东侧靠东墙设一张 4m 长、2m 宽的长桌（长边沿东西向）。
- [ ] req-bench-north：长桌北侧设一条 4m 长、1m 宽的长凳，其西端从门洞东侧开始，不侵占门内 1m 净空。
- [ ] req-bench-south：长桌南侧设一条 4m 长、1m 宽的长凳，与北凳相对布置。
- [ ] req-seats-10：就座共 10 座，南北两条长凳各 5 座（5+5）。
- [ ] req-counter：西墙中段设一张 2m 长、1m 深的柜台，作为主厅内的固定家具台面，不做单独隔间或操作间，也不延伸出备茶区。
- [ ] req-counter-no-service：柜台不设水槽、热水或其他备茶设备，不预留给排水与电源点位，仅为固定家具台面。
- [ ] req-stone-base：建筑坐于石基座上；石基座仅作墙下垫层与防潮层，不外挑成平台、不抬升室内地坪到需要踏步的高度。
- [ ] req-wood-wall-column：外墙与柱为木材（木墙木柱）。
- [ ] req-gable-tile-roof：屋面为双坡形式，覆深色瓦。
- [ ] req-eave-only：屋面只做出檐，不做檐下平台或檐廊；出檐下方不设铺装与可停留地面。
- [ ] req-block-budget：整体方块用量不超过 20000 方块；按 1 格≈1m 估算，10m×8m×约 6m 的主体体量远低于该上限。
- [ ] req-no-sign-ticket-frame：不设招牌、售票窗口或装饰性构架。
- [ ] req-site-stream-south：溪流位于场地南侧，是建筑的主要景观方向。
- [ ] req-site-road-north：村道位于场地北侧，建筑位于村口溪边。
- [ ] req-entrance-from-north：人流由北侧村道直接进入北墙门洞，入口朝北；入口处地面齐平、无踏步。
- [ ] req-view-frame：南墙 4m 大窗作为溪景取景框，是主厅的视觉中心，室内布置需让主要座席朝窗。
- [ ] constraint-con-outer-10x8：建筑外轮廓 10m×8m 矩形，不得超出。
- [ ] constraint-con-single-storey：单层建筑，无二层、无夹层、无楼梯、无地下层。
- [ ] constraint-con-interior-clear：室内净尺寸 8m×6m（48㎡）。
- [ ] constraint-con-wall-1m：外墙厚 1m。
- [ ] constraint-con-door-2m：北墙西段门洞净宽 2m。
- [ ] constraint-con-door-clear-1m：门内侧保留 1m 宽净空，不摆放家具。
- [ ] constraint-con-window-south：南墙唯一洞口：宽 4m、窗台高 1m、窗高 2m（洞口顶 3m）。
- [ ] constraint-con-material-selection：材料限定为石基座、木墙木柱、双坡深瓦。
- [ ] constraint-con-block-budget：方块总量不超过 20000 方块。
- [ ] constraint-con-entry-flush：室内外地面齐平，门洞处不设踏步或坡道；石基座仅作墙下垫层，不外挑成平台。

### 自动门槛

- 构建前按 gates.json 检查现有门槛能表达的部分：可达、结构跨度、悬空来源；不能表达的约束继续以 build-spec.json 为准。
- 构建前 lint 已检查：必须项覆盖、题面数字与 spec 一致、空间 / 洞口 / 路线引用、预算、禁项与任务长度。

### 自由发挥

- 在不改变主要布局、层数、外部尺寸、层高、入口位置、屋面形式和主要材质的前提下，构造做法、局部装饰、铺装图案、灯具与家具细节可自行处理。
- 若方案未包含室内，不要自行扩展完整内饰；若方案声明完整室内，必须完成主要空间、家具、楼层与固定家具，不能只做空壳。
- 遇到无法实现、与 spec 冲突或需要改方案的情况：停止并报告冲突位置、原因与建议，不要自行修改已确认方案。
