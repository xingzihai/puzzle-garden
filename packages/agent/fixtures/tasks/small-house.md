# M1-01 住宅 · 冒烟题：坡顶小屋

> task_id: `m1-01-small-house` ｜ family: `small-house` ｜ split: **dev** ｜ status: **第 10 步冒烟题**
> 用途：第 9 步 success 剧本与 `npm run agent --mock` 的夹具题面；不冒充 owner 认可。

## 一、must（硬要求，逐条可在图上指认）

1. **单栋住宅**：一栋矩形主体，外墙完整围合，内部留空。
2. **抬高台基**：高于草地面 1 格，台基轮廓向四边外挑 ≥1 格。
3. **一处入口**：南面有一处净宽 ≥1、净高 ≥2 的门洞。
4. **完整双坡屋顶**：屋脊沿东西向，屋面盖过外墙，有可读檐口。
5. 至少一处侧窗（东西立面之一，净宽 ≥1、净高 ≥1）。
6. 石基座与木质墙体形成一处克制的材质分区。

## 二、forbidden（禁止项）

- 禁第二栋建筑、禁楼梯与多层。
- 禁无支撑悬挑：屋面必须压在外墙上，不出现孤立悬空屋面板。
- 禁道路网 / 树群 / 水体等扩展场景。
- 禁内饰与灯饰：本阶段只做外观与可进入。

## 三、尺寸/规模范围

| 项               | 范围                 |
| ---------------- | -------------------- |
| 主体占地         | 长边 7–11、短边 7–11 |
| 最高点（含顶饰） | 7–12 格              |
| 台基外挑         | 1–2 格               |
| 层数             | 1 层                 |

## 四、风格与可观察条款（非审美真值）

- 风格意图：小体量、坡顶、石基木墙，比例协调。
- 可观察：台基与地面是否衔接、墙体是否闭合、门是否可辨、屋面是否覆盖墙顶。
- 未校准项不冒称机械。

## 五、交付与执行（沿用统一循环）

- 写代码 → `check_code` → `view_building` 看图 → 满意 `submit`。
